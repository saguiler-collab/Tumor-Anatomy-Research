# Pre-specified quantities

Files here are **choices fixed before their effect on any result was known.** That is the
whole reason the directory exists: a quantity chosen after seeing which choice improves the
ranking is selection on an outcome, which this project's invariants forbid.

Nothing here is a result. Nothing here is regenerated by a pipeline run. Each file is written
once, with its justification recorded in `docs/CORRECTIONS_REGISTRATION.md`, and **committed
before the quantity is used**, so the commit date is the evidence that the order was respected.

| file | what it fixes | registered as |
|---|---|---|
| `mrna_content_gbmap_10x.csv` | the per-type mRNA-content vector that converts RNA contributions to cellular abundance in Problem 2 | `CORRECTIONS_REGISTRATION.md` **C8** |
| `imc_anchored_prediction.md` | the ordering ACS must reproduce if anatomic concordance tracks an orthogonal **protein** ground truth (imaging mass cytometry) | `CORRECTIONS_REGISTRATION.md` **C10** |
| `biological_failure_factors.md` | the hypothesis, seven candidate factors with directions, model and falsification criterion for *when* bulk deconvolution fails in GBM | — (a new study, not a correction) |
| `immune_failure_factors.md` | the immune arm: a methylation-derived leukocyte fraction as a second independent ground truth, with the denominator mismatch and four predictions fixed before computing | — |

## `mrna_content_gbmap_10x.csv`

Per-type mean total UMI count over GBmap's **10x cells only**, computed from `raw/X` — the
genuine integer counts — on 4,062 cells stratified by cell type.

**Chosen on mechanism: UMIs count molecules, and mRNA content is a count of molecules.** The
three rejected alternatives, and why, are in C8. The short version is that pooling GBmap's
platforms measures platform rather than biology (73.9x spread against 2.897x within 10x,
because Smart-seq2 cells carry ~100x the reads of 10x cells and the platform mix differs
sharply by cell type), that Smart-seq2 read counts do not recover the ordering at all
(Tumor/T_cell 0.926), and that the sums the code currently passes are sums of **log** values
(`OPEN_DEFECTS.md` D16).

**Astrocyte rests on 77 cells** and is a diagnostic-only sidecar known to be unidentifiable
against Tumor. No definitional claim rests on it.

**This is not what the published leaderboard used.** That used a uniform vector, so the
conversion was the identity (D12). This vector is for Problem 2 going forward.
